# TikAuction V2 Prototype

Prototype dashboard mobile untuk aktivitas live.

Fitur:
- UI TikTok LIVE-style
- koneksi simulator host
- timer, pause, reset, selesai
- peserta
- event log
- simulasi gift menjadi poin virtual
- Express + Socket.IO sebagai fondasi server

Catatan:
Koneksi simulator BUKAN koneksi resmi ke TikTok LIVE. Prototype ini tidak memakai uang asli.
